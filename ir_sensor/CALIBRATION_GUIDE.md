# ИНСТРУКЦИЯ ПО КАЛИБРОВКЕ IR ДАТЧИКА

## Что делает калибровка

Калибровка настраивает датчик для правильного определения ребер на вращающейся ленте.

---

## ПЕРЕД НАЧАЛОМ

1. Лента должна вращаться с рабочей скоростью
2. На ленте минимум 3 ребра
3. Датчик установлен на рабочем расстоянии

---

## ФОРМАТ КОМАНД

Все команды в формате: `C<команда>A<адрес>D<данные>N<данные1>x`

Пример: `C6A0D0N0x` - где C6 это команда 6, остальные параметры по нулям, x - конец.

---

## ЗАПУСК КАЛИБРОВКИ

**Шаг 1. Запустить калибровку:**
```
C6A0D0N0x
```

**Шаг 2. Подождать 5-10 секунд**

В логе появятся сообщения:
```
Calibration started for 5000 ms
Phase 1: Time calibration
Edge #1: time=45 ms
Edge #2: time=47 ms
Phase 2: Distance calibration
Belt segment: avg=2134.5
```

**Шаг 3. Проверить результат**

Успех:
```
Calibration SUCCESS:
  Belt distance: avg=2145, threshold=1876
  Edges detected: 8, Belt samples: 1247
```

Неудача:
```
Calibration FAILED:
  Edges detected: 1 (min 3 required)
```

**Шаг 4. Сохранить настройки:**
```
C9A0D0N0x
```

Ответ: `C9 OKx`

Без сохранения настройки пропадут после перезагрузки!

---

## ПРОВЕРКА РАБОТЫ

**Получить текущее значение сигнала:**
```
C1A0D0N0x
```
Ответ: `C1D2134x` (значение 2134)

**Проверить обнаружен ли объект:**
```
C3A0D0N0x
```
Ответ: `C3D1x` (на ребре) или `C3D0x` (между ребрами)

При вращении ленты ответ должен чередоваться 0/1.

---

## НАСТРОЙКА ФИЛЬТРА

Обычно не требуется. Менять только если датчик работает нестабильно.

**Коэффициент k_H (быстрые изменения):**

Прочитать: `C4A0D0N0x` → Ответ: `C4D40x` (значение 40 = 0.4)

Установить 0.6: `C4A1D60N0x` → Ответ: `C4 OKx`

Больше значение (50-60) = быстрее реакция, больше помех
Меньше значение (30-40) = медленнее, но точнее

**Коэффициент k_L (медленные изменения):**

Прочитать: `C5A0D0N0x` → Ответ: `C5D10x` (значение 10 = 0.1)

Установить 0.15: `C5A1D15N0x` → Ответ: `C5 OKx`

Больше значение (15-20) = меньше сглаживания
Меньше значение (5-10) = сильнее подавление шума

После изменения сохранить: `C9A0D0N0x`

---

## РЕШЕНИЕ ПРОБЛЕМ

**Не обнаруживаются ребра:**
- Проверьте вращение ленты
- Проверьте сигнал: `C1A0D0N0x` (должно быть больше 500)
- Запустите калибровку заново

**Нестабильная работа:**
- Повторите калибровку
- Уменьшите коэффициенты: `C4A1D30N0x` и `C5A1D5N0x`
- Сохраните: `C9A0D0N0x`

**Перезагрузка устройства:**
```
C11A0D1N0x
```

---

## БЫСТРАЯ СПРАВКА КОМАНД

**C1A0D0N0x** - получить сигнал
**C3A0D0N0x** - проверить обнаружение (0 или 1)
**C4A0D0N0x** - прочитать k_H
**C4A1D60N0x** - установить k_H=0.6
**C5A0D0N0x** - прочитать k_L
**C5A1D15N0x** - установить k_L=0.15
**C6A0D0N0x** - ЗАПУСК КАЛИБРОВКИ
**C9A0D0N0x** - СОХРАНИТЬ В ПАМЯТЬ
**C11A0D1N0x** - перезагрузка

---
