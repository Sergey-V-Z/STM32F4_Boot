# Документация по измерению тока с помощью ACS712ELCTR-20B-T

## Описание датчика

**ACS712ELCTR-20B-T** - это датчик тока на основе эффекта Холла с гальванической развязкой.

### Основные характеристики:
- **Диапазон измерения**: ±20 Ампер
- **Чувствительность**: 100 мВ/А (0.1 В/А)
- **Выходное напряжение при 0А**: 2.5В (VCC/2 при VCC=5В)
- **Питание**: 5В
- **Изоляция**: 2.1 kVRMS минимум
- **Полоса пропускания**: 80 кГц
- **Время нарастания**: 5 мкс

### Документация
Datasheet: [Allegro ACS712](https://www.allegromicro.com/-/media/files/datasheets/acs712-datasheet.pdf)

## Схема подключения

В данном проекте датчик подключен к микроконтроллеру следующим образом:

```
ACS712 OUT (5V) ---> Делитель /2 ---> PA4 (ADC1_IN4)
                                      3.3V max
```

### Делитель напряжения
Так как ACS712 работает от 5В и выдает выходное напряжение в диапазоне 0-5В, а АЦП микроконтроллера STM32F4 работает с напряжением 0-3.3В, используется резистивный делитель напряжения на 2.

**Напряжения на выходе ACS712:**
- При токе -20А: ~0.5В → на PA4: ~0.25В
- При токе 0А: 2.5В → на PA4: ~1.25В
- При токе +20А: ~4.5В → на PA4: ~2.25В

## Реализация в коде (DMA режим с фильтром)

### Конфигурация АЦП
- **Режим**: Scan mode (сканирование)
- **Каналы**: 16 регулярных конверсий одного физического канала PA4
- **DMA**: DMA2 Stream0, Channel 0
- **Время выборки**: 112 циклов на каждое измерение
- **Разрешение**: 12 бит (0-4095)

### Глобальные переменные
```cpp
#define ADC_SAMPLES 16  // Количество измерений для усреднения
uint16_t adc_dma_buffer[ADC_SAMPLES];  // Буфер для DMA
volatile uint8_t adc_conversion_complete;  // Флаг завершения
float g_current_amperes;  // Ток в амперах
```

### Функции

#### `void ACS712_StartDMA_Conversion(void)`
Запускает преобразование АЦП с DMA (16 последовательных измерений).

**Использование:**
```cpp
ACS712_StartDMA_Conversion();
```

#### `uint16_t ACS712_MovingAverage(uint16_t* data, uint16_t size)`
Реализует фильтр скользящего среднего.

**Параметры:**
- `data` - указатель на массив данных АЦП
- `size` - размер массива (16)

**Возвращает**: Усредненное значение АЦП

**Алгоритм:**
1. Суммирует все 16 значений
2. Делит на 16
3. Возвращает среднее

#### `float ACS712_ProcessData(void)`
Обрабатывает данные из DMA буфера и преобразует в ток.

**Алгоритм:**
1. Применяет фильтр скользящего среднего к 16 измерениям
2. Преобразует усредненное значение АЦП в напряжение
3. Учитывает делитель напряжения (×2)
4. Рассчитывает ток по формуле: `I = (V - 2.5) / 0.1`
5. Обновляет глобальную переменную `g_current_amperes`

**Возвращает**: Ток в амперах

#### `void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef* hadc)`
Callback, вызываемый автоматически при завершении DMA передачи.

**Действия:**
1. Устанавливает флаг `adc_conversion_complete = 1`
2. Автоматически вызывает `ACS712_ProcessData()`
3. Обновляет `g_current_amperes`

### Работа в основном цикле

```cpp
for(;;)
{
    // Запускаем преобразование АЦП с DMA
    ACS712_StartDMA_Conversion();
    
    // Ждем завершения конверсии (с таймаутом 100 мс)
    uint32_t timeout = 100;
    uint32_t start_tick = osKernelSysTick();
    while (!adc_conversion_complete && (osKernelSysTick() - start_tick) < timeout)
    {
        osDelay(1);
    }
    
    // Значение тока уже обработано в callback: g_current_amperes
    
    osDelay(100); // Период опроса 100 мс
}
```

### Доступ к значению тока из других задач

```cpp
extern float g_current_amperes;  // Объявление extern

// Использование
if (g_current_amperes > 15.0f) {
    // Защита от перегрузки по току
    PWM_DisableAll();
}
```

### Интеграция с API

Команда **19** для получения тока через TCP/IP:

**Запрос:**
```
C19A0D0N0x
```

**Ответ:**
```
C19D5234x  // 5234 мА = 5.234 А
```

## Преимущества DMA режима с фильтром

1. **Снижение шума**: 16 измерений усредняются, что значительно уменьшает влияние шумов
2. **Неблокирующая работа**: CPU не занят ожиданием завершения АЦП
3. **Высокая точность**: Фильтр скользящего среднего обеспечивает стабильные показания
4. **Эффективность**: DMA передает данные без участия CPU

## Характеристики измерения

- **Частота опроса**: 10 Гц (каждые 100 мс)
- **Количество усреднений**: 16 измерений
- **Время одного измерения**: ~112 циклов АЦП
- **Разрешение по току**: ~0.01 А (при 12-бит АЦП)

## Калибровка

### Калибровка нуля
Для точного измерения может потребоваться калибровка при отсутствии тока:

1. Отключите нагрузку (ток = 0А)
2. Измерьте напряжение на PA4
3. Если значение отличается от 1.25В, скорректируйте константу `zero_current_voltage` в функции `ACS712_ProcessData()`

### Компенсация смещения
```cpp
// Добавьте калибровочную константу в ACS712_ProcessData()
float calibration_offset = 0.0f;  // Корректировка в амперах
float current = (voltage_acs712 - zero_current_voltage) / sensitivity + calibration_offset;
```

## Рекомендации

1. **Фильтр**: Встроенный фильтр скользящего среднего обеспечивает стабильные показания
2. **Защита от перегрузки**: Реализуйте мониторинг тока и отключение при превышении порога
3. **Частота опроса**: Можно увеличить частоту, уменьшив задержку в основном цикле
4. **Количество усреднений**: При необходимости можно изменить `ADC_SAMPLES` (не забудьте обновить конфигурацию АЦП в CubeMX)

## Примечания

- Все функции находятся в защищенной области `USER CODE` и не будут удалены при регенерации CubeMX
- DMA обеспечивает минимальную нагрузку на CPU
- Фильтр скользящего среднего эффективно подавляет высокочастотные шумы
- При отсутствии делителя требуется адаптация под 5В питание АЦП
- Учитывайте температурный дрейф датчика (±1.5% при 25°C)
- Для измерения переменного тока требуется дополнительная обработка (RMS расчет)
