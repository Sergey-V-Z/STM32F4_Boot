# Документация по измерению тока с помощью ACS712ELCTR-20A-T

## Описание датчика

**ACS712ELCTR-20A-T** - это датчик тока на основе эффекта Холла с гальванической развязкой.

### Основные характеристики:
- **Диапазон измерения**: ±20 Ампер
- **Чувствительность**: 100 мВ/А (0.1 В/А)
- **Выходное напряжение при 0А**: 2.5В (VCC/2 при VCC=5В)
- **Питание**: 5В
- **Изоляция**: 2.1 kVRMS минимум
- **Полоса пропускания**: 80 кГц
- **Время нарастания**: 5 мкс

### Документация
Datasheet: [Allegro ACS712](https://www.allegromicro.com/-/media/files/datasheets/acs712-datasheet.pdf)

## Схема подключения

В данном проекте датчик подключен к микроконтроллеру следующим образом:

```
ACS712 OUT (5V) ---> Делитель /2 ---> PA4 (ADC1_IN4)
                                      3.3V max
```

### Делитель напряжения
Так как ACS712 работает от 5В и выдает выходное напряжение в диапазоне 0-5В, а АЦП микроконтроллера STM32F4 работает с напряжением 0-3.3В, используется резистивный делитель напряжения на 2.

**Напряжения на выходе ACS712:**
- При токе -20А: ~0.5В → на PA4: ~0.25В
- При токе 0А: 2.5В → на PA4: ~1.25В
- При токе +20А: ~4.5В → на PA4: ~2.25В

## Реализация в коде (DMA режим с двухуровневой фильтрацией)

### Конфигурация АЦП
- **Режим**: Scan mode (сканирование)
- **Каналы**: 16 регулярных конверсий одного физического канала PA4
- **DMA**: DMA2 Stream0, Channel 0
- **Время выборки**: 112 циклов на каждое измерение
- **Разрешение**: 12 бит (0-4095)

### Система фильтрации (двухуровневая)

**Уровень 1 - Аппаратная фильтрация АЦП:**
- Фильтр скользящего среднего на 16 измерениях АЦП
- Подавление высокочастотного шума измерений

**Уровень 2 - Программная фильтрация:**
- Экспоненциальный фильтр низких частот (EMA - Exponential Moving Average)
- Коэффициент сглаживания: 0.15 (настраиваемый)
- Подавление выбросов и резких скачков показаний

### Глобальные переменные
```cpp
#define ADC_SAMPLES 16  // Количество измерений для усреднения
#define CURRENT_FILTER_ALPHA 0.15f  // Коэффициент экспоненциального фильтра
uint16_t adc_dma_buffer[ADC_SAMPLES];  // Буфер для DMA
volatile uint8_t adc_conversion_complete;  // Флаг завершения
float g_current_amperes;  // Фильтрованный ток в амперах
float g_current_filtered;  // Промежуточное значение фильтра
volatile uint8_t g_current_filter_initialized;  // Флаг инициализации фильтра
```

### Функции

#### `void ACS712_StartDMA_Conversion(void)`
Запускает преобразование АЦП с DMA (16 последовательных измерений).

**Использование:**
```cpp
ACS712_StartDMA_Conversion();
```

#### `uint16_t ACS712_MovingAverage(uint16_t* data, uint16_t size)`
Реализует фильтр скользящего среднего.

**Параметры:**
- `data` - указатель на массив данных АЦП
- `size` - размер массива (16)

**Возвращает**: Усредненное значение АЦП

**Алгоритм:**
1. Суммирует все 16 значений
2. Делит на 16
3. Возвращает среднее

#### `float ACS712_ProcessData(void)`
Обрабатывает данные из DMA буфера и преобразует в ток с двухуровневой фильтрацией.

**Алгоритм:**
1. Применяет фильтр скользящего среднего к 16 измерениям АЦП (подавление аппаратного шума)
2. Преобразует усредненное значение АЦП в напряжение
3. Учитывает делитель напряжения (×2)
4. Рассчитывает мгновенный ток по формуле: `I = (V - 2.5) / 0.1`
5. Применяет экспоненциальный фильтр (EMA) для подавления выбросов:
   - При первом измерении: инициализирует фильтр текущим значением
   - При последующих: `filtered = 0.15 × current_raw + 0.85 × filtered_prev`
6. Обновляет глобальную переменную `g_current_amperes` фильтрованным значением

**Возвращает**: Фильтрованный ток в амперах

**Настройка фильтрации:**
- Изменение `CURRENT_FILTER_ALPHA` (0.0-1.0):
  - Меньше (0.05-0.1) = плавнее, но медленнее реакция
  - Больше (0.2-0.3) = быстрее реакция, но меньше фильтрация
  - Рекомендуемое значение: 0.15

**Возвращает**: Ток в амперах

#### `void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef* hadc)`
Callback, вызываемый автоматически при завершении DMA передачи.

**Действия:**
1. Устанавливает флаг `adc_conversion_complete = 1`
2. Автоматически вызывает `ACS712_ProcessData()`
3. Обновляет `g_current_amperes`

### Работа в основном цикле

```cpp
for(;;)
{
    // Запускаем преобразование АЦП с DMA
    ACS712_StartDMA_Conversion();
    
    // Ждем завершения конверсии (с таймаутом 100 мс)
    uint32_t timeout = 100;
    uint32_t start_tick = osKernelSysTick();
    while (!adc_conversion_complete && (osKernelSysTick() - start_tick) < timeout)
    {
        osDelay(1);
    }
    
    // Значение тока уже обработано в callback: g_current_amperes
    
    osDelay(100); // Период опроса 100 мс
}
```

### Доступ к значению тока из других задач

```cpp
extern float g_current_amperes;  // Объявление extern

// Использование
if (g_current_amperes > 15.0f) {
    // Защита от перегрузки по току
    DAC_DisableAll();
}
```

**Запрос:**

```

**Ответ:**
```

**Пример работы фильтра:**

```
C19D1087x, C19D910x, C19D346x, C19D910x, C19D1071x, C19D378x, C19D1184x...
```

С двухуровневой фильтрацией (стабильные показания):
```
C19D900x, C19D902x, C19D898x, C19D901x, C19D900x, C19D899x...
```

## Преимущества двухуровневой фильтрации

1. **Аппаратный уровень (АЦП)**:
   - 16 измерений усредняются (фильтр скользящего среднего)
   - Подавление высокочастотного шума АЦП
   - DMA обеспечивает неблокирующую работу CPU

2. **Программный уровень (EMA)**:
   - Экспоненциальное сглаживание показаний
   - Подавление выбросов и резких скачков (от ±838 мА до ±2-3 мА)
   - Стабильные показания при колебаниях нагрузки
   - Быстрая реакция на реальные изменения тока

3. **Общие преимущества**:
   - Стабильность измерений улучшена в ~280 раз
   - Минимальная нагрузка на CPU благодаря DMA
   - Настраиваемый баланс между скоростью реакции и фильтрацией

## Характеристики измерения

- **Частота опроса**: 10 Гц (каждые 100 мс)
- **Количество усреднений АЦП**: 16 измерений
- **Коэффициент EMA фильтра**: 0.15 (настраиваемый)
- **Время одного измерения АЦП**: ~112 циклов
- **Разрешение по току**: ~0.01 А (при 12-бит АЦП)
- **Стабильность показаний**: ±2-3 мА (после фильтрации)
- **Время установления**: ~5-7 измерений (0.5-0.7 сек)

## Настройка фильтрации

### Настройка коэффициента экспоненциального фильтра

Измените константу `CURRENT_FILTER_ALPHA` в [freertos.cpp](Core/Src/freertos.cpp):

```cpp
#define CURRENT_FILTER_ALPHA 0.15f  // Значение от 0.0 до 1.0
```

**Рекомендации по выбору коэффициента:**

| Alpha | Описание | Применение |
|-------|----------|------------|
| 0.05-0.1 | Очень плавное сглаживание | Стабильная нагрузка, максимальная фильтрация |
| 0.15-0.2 | Сбалансированное (рекомендуется) | Универсальное применение |
| 0.25-0.35 | Быстрая реакция | Динамичная нагрузка, быстрые изменения |
| 0.5+ | Минимальная фильтрация | Отладка, тестирование |

**Время установления фильтра:**
- Alpha = 0.1: ~7-10 измерений (0.7-1.0 сек)
- Alpha = 0.15: ~5-7 измерений (0.5-0.7 сек) ← текущее
- Alpha = 0.25: ~3-5 измерений (0.3-0.5 сек)

### Настройка количества измерений АЦП

Для изменения `ADC_SAMPLES`:
1. Измените константу в коде
2. Обновите конфигурацию в STM32CubeMX (NbrOfConversion)
3. Перегенерируйте код

## Калибровка

### ⚡ Автоматическая калибровка нуля (рекомендуется)

Для компенсации смещения датчика используйте встроенную функцию калибровки с автоматическим сохранением во flash.

**Через API команду 20:**
1. Отключите всю нагрузку (все каналы PWM в 0 или выключены)
2. Убедитесь, что ток = 0А
3. Отправьте команду: `C20A0D0N0x`
4. Контроллер выполнит 10 измерений и вычислит среднее смещение
5. В ответе получите найденное смещение (например, `C20D-45x` = -45 мА)
6. **Калибровка автоматически сохранится во flash память**
7. При перезагрузке/включении калибровка загрузится автоматически
8. Все последующие измерения будут автоматически скорректированы

**Дополнительные команды калибровки:**
- `C20A1D0N0x` - прочитать текущее смещение калибровки
- `C20A2D0N0x` - временно сбросить калибровку (не сохраняется)

**Хранение калибровки:**
- Калибровочные данные сохраняются в отдельной области flash (адрес 0x1000)
- Используется отдельная структура `calibration_t` (не затрагивает `settings_t`)
- Защита целостности данных: magic key + CRC32
- Автоматическая загрузка при старте контроллера
- Калибровка сохраняется между перезагрузками

**Через код:**
```cpp
// Вызовите функцию при отсутствии нагрузки
ACS712_CalibrateZero();  // Автоматически сохранит во flash

// Текущее смещение сохранено в глобальной переменной
extern float g_current_zero_offset;  // в амперах
```

**Принцип работы:**
- Функция делает 10 измерений тока с интервалом 50 мс
- Вычисляет среднее значение (это смещение датчика)
- Сохраняет смещение в `g_current_zero_offset`
- При каждом последующем измерении это смещение вычитается из результата

### 🔧 Ручная калибровка (для отладки)

**Калибровка опорного напряжения:**
1. Отключите нагрузку (ток = 0А)
2. Измерьте напряжение на PA4
3. Если значение отличается от 1.25В, скорректируйте константу `zero_current_voltage` в функции `ACS712_ProcessData()`

**Ручная установка смещения в коде:**
```cpp
// Установите смещение напрямую (в амперах)
g_current_zero_offset = -0.045f;  // Компенсация -45 мА
```

## Рекомендации

1. **Двухуровневая фильтрация**: Обеспечивает отличную стабильность при сохранении отклика
2. **Защита от перегрузки**: Реализуйте мониторинг тока и отключение при превышении порога
3. **Частота опроса**: Можно увеличить частоту, уменьшив задержку в основном цикле (учтите время установления фильтра)
4. **Настройка баланса**: Используйте меньший `CURRENT_FILTER_ALPHA` для стабильных нагрузок, больший - для динамичных

## Примечания

- Все функции находятся в защищенной области `USER CODE` и не будут удалены при регенерации CubeMX
- DMA обеспечивает минимальную нагрузку на CPU
- Фильтр скользящего среднего эффективно подавляет высокочастотные шумы
- При отсутствии делителя требуется адаптация под 5В питание АЦП
- Учитывайте температурный дрейф датчика (±1.5% при 25°C)
- Для измерения переменного тока требуется дополнительная обработка (RMS расчет)

## Калибровка

### Калибровка нуля
Для точного измерения может потребоваться калибровка при отсутствии тока:

1. Отключите нагрузку (ток = 0А)
2. Измерьте напряжение на PA4
3. Если значение отличается от 1.25В, скорректируйте константу `zero_current_voltage` в функции

### Компенсация смещения
```cpp
// Добавьте калибровочную константу
float calibration_offset = 0.0f;  // Корректировка смещения в амперах
float current = (voltage_acs712 - zero_current_voltage) / sensitivity + calibration_offset;
```

## Рекомендации

1. **Фильтрация**: Для более стабильных показаний можно добавить программный фильтр (скользящее среднее)
2. **Защита от перегрузки**: Реализовать мониторинг тока и отключение при превышении порога
3. **Частота опроса**: В текущей реализации опрос происходит каждые 100мс (10 Гц). При необходимости можно увеличить частоту
4. **DMA**: Для высокочастотного мониторинга можно настроить АЦП с DMA для автоматического сбора данных

## Примечания

- При отсутствии делителя напряжения требуется адаптация под 5В питание АЦП
- Учитывайте температурный дрейф датчика (±1.5% при 25°C)
- Для измерения переменного тока требуется дополнительная обработка (RMS расчет)
