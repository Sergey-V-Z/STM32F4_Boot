# Описание API-команд 6-канального LED драйвера

## Формат команд

Все команды следуют общему формату:
```
C<номер_команды>A<адрес>D<данные>N<данные1>x
```

Где:
- **C** - префикс команды
- **<номер_команды>** - номер команды (числовое значение)
- **A** - префикс адреса
- **<адрес>** - адрес переменной/параметра
- **D** - префикс данных
- **<данные>** - основное значение данных
- **N** - префикс дополнительных данных
- **<данные1>** - дополнительное значение данных
- **x** - разделитель команд

## Таблица API-команд

### Команды управления PWM каналами (4-8)

**Команда 4**: Включение/выключение канала
| Параметры | Функция | Пример |
|-----------|---------|--------|
| A=0, D=0/1, N=канал(0-5) | Вкл/выкл одного канала | `C4A0D1N2x` - включить канал 2 |
| A=1+, D=0/1 | Вкл/выкл всех каналов | `C4A1D1N0x` - включить все |

**Команда 5**: Установка PWM (значение 0-1000)
| Параметры | Функция | Пример |
|-----------|---------|--------|
| A=0, D=PWM, N=канал(0-5) | Установка для одного канала | `C5A0D500N2x` - канал 2 на 50% |
| A=1+, D=PWM | Установка для всех каналов | `C5A1D750N0x` - все на 75% |

**Команда 6**: Чтение PWM
- `C6A0D0N<канал>x` → Возвращает значение PWM (0-1000)
- Пример: `C6A0D0N3x` - читать PWM канала 3

**Команда 8**: Проверка состояния канала
- `C8A0D0N<канал>x` → Возвращает 1 (вкл) или 0 (выкл)
- Пример: `C8A0D0N4x` - проверить канал 4

### Команды системные (9-11)

**Команда 9**: Сохранение настроек во флэш
- `C9A0D0N0x` → "OK"

**Команда 10**: Загрузка настроек
- `C10A0D<значение>N0x` → "OK"
- Устанавливает IP_end_from_settings

**Команда 11**: Перезагрузка контроллера
- `C11A0D0N0x` → "OK" (без перезагрузки)
- `C11A0D1N0x` → "OK" (с перезагрузкой)

### Команды сетевые настройки (12-16)

**Команда 12**: DHCP
- `C12A0D0N0x` → Отключить DHCP
- `C12A0D1N0x` → Включить DHCP

**Команда 13**: IP-адрес (по октетам 0-3)
```
C13A0D192N0x  → Установить IP[0] = 192
C13A1D168N0x  → Установить IP[1] = 168
C13A2D1N0x    → Установить IP[2] = 1
C13A3D100N0x  → Установить IP[3] = 100
Результат: 192.168.1.100
```

**Команда 14**: Маска подсети (по октетам 0-3)
```
C14A0D255N0x  → Mask[0] = 255
C14A1D255N0x  → Mask[1] = 255
C14A2D255N0x  → Mask[2] = 255
C14A3D0N0x    → Mask[3] = 0
Результат: 255.255.255.0
```

**Команда 15**: Шлюз (по октетам 0-3)
```
C15A0D192N0x  → Gateway[0] = 192
C15A1D168N0x  → Gateway[1] = 168
C15A2D1N0x    → Gateway[2] = 1
C15A3D1N0x    → Gateway[3] = 1
Результат: 192.168.1.1
```

**Команда 16**: MAC-адрес (по байтам 0-5)
```
C16A0D0x02N0x   → MAC[0] = 0x02
C16A1D0x03N0x   → MAC[1] = 0x03
...
C16A5D0x06N0x   → MAC[5] = 0x06
```

### Команда мониторинга (19)

**Команда 19**: Чтение тока с датчика ACS712
- **Формат**: `C19A0D0N0x`
- **Ответ**: `C19D<значение>x` - значение в миллиамперах
- **Примеры**:
  - Запрос: `C19A0D0N0x`
  - Ответ: `C19D5234x` → 5234 мА = **5.234 А**
  - Ответ: `C19D1500x` → 1500 мА = **1.500 А**
  - Ответ: `C19D-234x` → -234 мА = **-0.234 А** (отрицательный ток)

**Команда 20**: Калибровка нуля датчика тока
- **Формат A=0**: `C20A0D0N0x` - выполнить калибровку нуля (при отключенной нагрузке)
  - **Ответ**: `C20D<смещение>x` - найденное смещение в мА
  - **Пример**: `C20D-45x` → смещение -45 мА было скомпенсировано
  - **Важно**: Калибровка автоматически сохраняется во flash и загружается при старте
- **Формат A=1**: `C20A1D0N0x` - прочитать текущее калибровочное смещение
  - **Ответ**: `C20D<смещение>x` - текущее смещение в мА
- **Формат A=2**: `C20A2D0N0x` - сбросить калибровку (смещение = 0)
  - **Ответ**: `OK`
  - **Примечание**: Сброс НЕ сохраняется автоматически. Для постоянного сброса выполните калибровку с нулевым током.

**Процедура калибровки:**
1. Отключите всю нагрузку (ток должен быть 0А)
2. Отправьте команду `C20A0D0N0x`
3. Контроллер выполнит 10 измерений и вычислит среднее смещение
4. В ответе получите найденное смещение
5. Калибровка автоматически сохранится во flash память
6. При перезагрузке калибровка загрузится автоматически
7. Все последующие измерения будут автоматически скорректированы

**Технические характеристики датчика ACS712ELCTR-20A-T:**
- Диапазон измерения: **-20А до +20А**
- Чувствительность: 100 мВ/А
- Метод измерения: DMA с фильтром скользящего среднего (16 измерений)
- Частота опроса: 10 Гц (обновление каждые 100 мс)
- Точность: ±1.5% при 25°C

## Надёжность записи в ЦАП (защита от помех на I2C)

Каждая запись в MCP4725 (команды 4 mode=0/1, 21, 23, 25) теперь:
1. Пишется по I2C.
2. Проверяется обратным чтением (readback) — сравнивается с тем, что реально должно было лечь в регистр ЦАП.
3. При несовпадении или ошибке I2C — повторяется, всего до 3 попыток.

Итоговый результат (после всех ретраев) виден сразу в ответе на ту же команду:
- **cmd 4** (mode=0/1 — мгновенное вкл/выкл), **cmd 25** — `C4 OKx` / `C4 FAILx`, `C25 OKx` / `C25 FAILx`.
- **cmd 21** (все каналы, A=6+) — `C21 OKx` / `C21 FAILx`.
- **cmd 21** (один канал) — возвращаемое значение `C21D<dac_count>x` уже подтверждено обратным чтением; при сбое записи значение останется прежним (отличным от того, что должно было получиться из заданного процента) — так клиент видит несовпадение.

**cmd 4** mode=3/4 (плавное fade-вкл/выкл) — по-прежнему асинхронная операция, статус её результата не возвращается.

## Дамп лог-буфера (cmd 28)

В RAM крутится кольцевой буфер на **4096 байт**, который дублирует байт-в-байт всё, что прошивка сейчас отправляет в отладочный UART (`STM_LOG`/`STM_LOG_xx`, используется по всему коду). Это позволяет забрать недавнюю историю лога по TCP без физического подключения к UART.

- **Запрос**: `C28A0D0N0x` (параметры A/D/N зарезервированы, пока не используются).
- **Ответ**: `C28D<N>:<N сырых байт>x`, где `N` — десятичная длина в байтах.
- **Неразрушающее чтение** — дамп не очищает буфер, он продолжает копиться и перезаписывать самые старые данные по кругу. Повторный дамп без новой активности вернёт тот же контент.
- Пока буфер ни разу не заполнился с момента старта, `N` < 4096; после — всегда ровно 4096.

**⚠️ Формат ответа этой команды НЕЛЬЗЯ разбирать как обычные команды протокола.** Сырые байты дампа — это реальный текст лога и могут содержать произвольные символы, включая `x`, `C`, `D`, `A`, `N`, цифры и служебные байты (`\r`, `\x03`, `\x04`). Клиент обязан:
1. Прочитать `C28D`, затем десятичные цифры до символа `:` — это длина `N`.
2. Прочитать **ровно** `N` байт после `:` как есть, не пытаясь искать в них разделители команд.
3. Завершающий `x` после этих `N` байт — просто для единообразия с остальным протоколом, использовать его как маркер конца **нельзя** (может встретиться внутри самого дампа).

Пример: `C28A0D0N0x` → `C28D42:Connect open\r\x03\x04TCP CMD: C19A0D0N0x\r\x03\x04x`

Учитывая небольшой `TCP_SND_BUF` в конфигурации lwIP, дамп, близкий к полным 4KB, может уйти клиенту за несколько TCP-раундов — это ожидаемо, не ошибка.

## Коды ошибок

### Ошибки формата сообщения
- **"wrong format in C flag"** - ошибка в префиксе команды
- **"wrong format in A flag"** - ошибка в префиксе адреса
- **"wrong format in D flag"** - ошибка в префиксе данных
- **"wrong format in N flag"** - ошибка в префиксе дополнительных данных
- **"wrong format in x flag"** - ошибка в разделителе
- **"err after C is not number"** - после C не число
- **"err after A is not number"** - после A не число
- **"err after D is not number"** - после D не число
- **"err after N is not number"** - после N не число
- **"err format message"** - общая ошибка формата сообщения
- **"Command does not exist"** - команда не существует
- **"Invalid channel"** - неверный номер канала (вне диапазона 0-5)

| Параметр | Диапазон | Описание |
|----------|----------|----------|

| Ток ACS712 | -20000 до +20000 | Значение в миллиамперах (мА) |

## Примеры использования

### 🔧 Быстрый старт - включение каналов
```
C4A1D1N0x           → Включить все каналы
C5A1D500N0x         → Установить 50% PWM на всех
C9A0D0N0x           → Сохранить настройки
```

### 💡 Управление одним каналом
```
C4A0D1N2x           → Включить канал 2
C5A0D750N2x         → PWM 75% для канала 2
C6A0D0N2x           → Прочитать PWM канала 2
C8A0D0N2x           → Проверить состояние канала 2
```

### 🌐 Настройка сети
```
# Выключить DHCP
C12A0D0N0x
```

## ⚠️ Важные примечания

### Сохранение настроек
После изменения сетевых параметров (IP, маска, шлюз, MAC, DHCP) обязательно:
1. Сохранить командой `C9A0D0N0x`
2. Перезагрузить командой `C11A0D1N0x`

### PWM значения
Диапазон 0-1000:
- **0** = 0% (выключено)
- **500** = 50%
- **1000** = 100% (максимум)

### Датчик тока ACS712
Команда `C19A0D0N0x` возвращает значение в **миллиамперах**:
- Ответ `C19D5234x` = **5.234 А** (положительный ток)
- Ответ `C19D-1500x` = **-1.500 А** (отрицательный ток)
- Для получения ампер: значение ÷ 1000
- Диапазон: **-20000 до +20000 мА** (от -20А до +20А)

**Технология измерения:**
- DMA режим с автоматическим сбором 16 измерений
- Фильтр скользящего среднего для подавления шумов
- Обновление значения каждые 100 мс
- Высокая точность благодаря усреднению

### Номера каналов
Система имеет **6 каналов**: 0, 1, 2, 3, 4, 5

### Сетевые настройки
IP, маска и шлюз настраиваются по 4 команды (по октетам):
```
IP[0].IP[1].IP[2].IP[3]
```

### Валидация команд
Система проверяет:
- ✓ Корректность формата (C...A...D...N...x)
- ✓ Числовые значения после каждого флага
- ✓ Диапазоны параметров (каналы, PWM, и т.д.)

### TCP соединение
- Все команды передаются по **протоколу TCP**
- Поддержка одновременных подключений
- Обработка команд в порядке получения
- Возможность отправки пакета команд в одном сообщении
