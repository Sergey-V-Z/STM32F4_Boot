# Автоматический поиск устройств при загрузке

## Обзор изменений

Реализована система автоматического определения подключенных вторичных плат (LED_DRV, PWR_LOAD) при каждом запуске системы.

## Основные возможности

### 1. Автоматический поиск при старте
- При каждом запуске системы автоматически сканируются все UART адреса (1-16)
- Найденные устройства сохраняются в массив `devices[]`
- Создается привязка каналов через массив `NameCH[]`
- Выводятся детальные логи о найденных устройствах

### 2. Ручной режим
- Кнопка "Автозаполнение" в settings_tool по-прежнему работает
- При нажатии запускается принудительный поиск устройств

## Алгоритм работы

### При загрузке системы (mainTask):

1. **Поиск устройств**
   ```
   auto_search_dev() → сканирует UART адреса 1-16
   ```

2. **Обновление глобального счетчика**
   ```
   pcs_dev = found_count → сохраняет количество найденных устройств
   ```

3. **Вывод информации**
   ```
   Для каждого найденного устройства выводится:
   - Порядковый номер
   - Адрес устройства
   - Тип устройства (LED_DRV/PWR_LOAD)
   ```

4. **Создание привязки каналов**
   ```
   Заполнение массива NameCH[] для работы с каналами
   ```

## Логи

### При успешном старте:
```
=== Device Auto-Discovery Start ===
Found 2 devices via UART
  Device 0: Addr=1, Type=LED_DRV
  Device 1: Addr=2, Type=PWR_LOAD
=== Device Auto-Discovery Complete ===
```

### Если устройства не найдены:
```
=== Device Auto-Discovery Start ===
Found 0 devices via UART
=== Device Auto-Discovery Complete ===
```

## Новая функция

### devices_auto_discover_and_init()
Главная функция автоматического поиска и инициализации. Вызывается при старте системы в `mainTask()`.

**Алгоритм:**
1. Выполняет сканирование UART через `auto_search_dev()`
2. Обновляет глобальную переменную `pcs_dev`
3. Выводит информацию о каждом найденном устройстве
4. Создает привязку каналов в массиве `NameCH[]` с защитой мутексом

## Преимущества системы

1. **Автоматизация** - устройства определяются автоматически при каждой загрузке
2. **Простота** - не требуется ручное вмешательство пользователя
3. **Прозрачность** - детальные логи позволяют отслеживать процесс
4. **Надежность** - защита мутексом при работе с общими данными
5. **Обратная совместимость** - ручной режим "Автозаполнение" продолжает работать

## Использование

### Автоматический режим (основной)
1. Подключите вторичные платы к UART/RS-485
2. Включите устройство
3. Система автоматически найдет все подключенные устройства
4. Информация о найденных устройствах отобразится в логах

### Ручной режим (опциональный)
1. Подключите settings_tool
2. Нажмите кнопку "Автозаполнение"
3. Система выполнит поиск принудительно

## Диагностика

### Проверка логов
Подключите UART6 (логгер) и отслеживайте сообщения:
- `Device Auto-Discovery Start` - начало поиска
- `Found X devices` - количество найденных устройств
- `Device N: Addr=X, Type=Y` - информация о каждом устройстве
- `Device Auto-Discovery Complete` - завершение поиска

### Типичные проблемы

**Устройства не находятся (Found 0 devices):**
- Проверьте подключение UART/RS-485
- Убедитесь что вторичные платы запитаны
- Проверьте адреса плат (должны быть 1-16)
- Проверьте правильность подключения RS-485 (A, B линии)

**Находится меньше устройств чем подключено:**
- Проверьте стабильность питания вторичных плат
- Убедитесь что адреса устройств не дублируются
- Проверьте качество связи по RS-485

## Совместимость

- Работает с существующим протоколом UART
- Не влияет на работу settings_tool
- Не требует изменений в settings_tool
- Полностью обратно совместимо с предыдущей версией
- Автоматический поиск не мешает ручному режиму
